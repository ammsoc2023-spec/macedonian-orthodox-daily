MPC Church Calendar 2026 – offline PWA (EN / МК)
Static files only. Serve this folder over HTTPS (any static host: GitHub Pages, Netlify, Cloudflare Pages, Vercel...).
Open the URL on the phone once (it caches all 365 days), then:
 iPhone (Safari): Share → Add to Home Screen.   Android (Chrome): menu ⋮ → Install app / Add to Home screen.
Data: data/2026-MM.json (one per month, lazy-loaded), data/index.json (search), data/about.json.
Text is exported unchanged from the builder used for MPC_Calendar_2026_Full_Year_Daily_EN-MK.docx.


Day icons (Nov 2026): each day ends with a traditional Orthodox icon (saint, feast or Gospel scene) from Wikimedia Commons, with an EN/MK caption and a source/author/licence credit. Images: img/icons/*.webp (190 files, ~9 MB, cached on demand + warmed in the background by sw.js into cache 'mpc-icons-v1'). Mapping and credits: data/icons.json. Build scripts: /workspace/icons_work/ (daymap.txt, picks.py, build_icons.py, make_icons_json.py).
